## Timeline themes

The Timeline flame graph and the Call Tree Name column are colored by event category using the active theme. Configure themes from `preferences -> extensions -> Apex Log Analyzer` or in `settings.json`.

### Select a theme

Use `lana.timeline.activeTheme` to pick one of the 19 built-in themes, or the name of a custom theme you have defined. You can also select **Settings → Apex Log Analyzer → Timeline → Active Theme**.

Or run **Log: Timeline Theme** from the Command Palette to switch theme without opening settings. Use the arrow keys to preview each theme, then press `Enter` to keep it or `Esc` to go back to the previous theme. The Timeline and Call Tree update instantly.

The built-in themes are **50 Shades of Green** (the default), 50 Shades of Green Bright, Botanical Twilight, Catppuccin, Chrome, Dracula, Dusty Aurora, Firefox, Flame, Forest Floor, Garish, Material, Modern, Monokai Pro, Nord, Nord Forest, Okabe-Ito, Salesforce and Solarized.

### Custom themes

Define your own with `lana.timeline.customThemes`, or in **Settings → Apex Log Analyzer → Timeline → Custom Themes**. Each key is a theme name, and each value sets the eight category colors in hex:

- `apex` - Apex method entry and exit events
- `codeUnit` - Code Unit events
- `system` - System method calls
- `automation` - Workflow, Flow and Process Builder events
- `dml` - DML operations (insert, update, delete and more)
- `soql` - SOQL queries
- `callout` - HTTP callout events
- `validation` - Validation rule events

Custom themes show in the theme picker with the built-in themes. Set `lana.timeline.activeTheme` to a custom theme's name to use it.

:::note
A custom theme cannot replace a built-in theme. If a custom theme has the same name as a built-in theme, the built-in theme is used.
:::

### Frame details on hover

`lana.timeline.showTooltip` (default `true`) shows a details panel when you hover or select a frame on the Timeline. The Timeline toolbar has a button for the same setting. Turn it off to read the chart without the panel; the [inspector](./features/inspector.md) still shows the details of the selected frame.

## Call Tree category coloring

The Call Tree colors its Name column by event category using the active timeline theme. A color chip is shown by default; enable **Colorize Call Tree category names** (`lana.callTree.categoryColorize`) under `preferences -> extensions -> Apex Log Analyzer` to tint the whole cell instead. See [Call Tree → Category Coloring](./features/calltree.mdx#category-coloring).

## Inspector

The [inspector](./features/inspector.md) remembers where you dock it and how big it is:

- `lana.inspector.position` - where it docks: `right` (default), `left` or `bottom`.
- `lana.inspector.size` - its width (or height when docked to the bottom), in pixels.

Both update as you drag or re-dock the inspector, so you rarely need to edit them by hand.

Collapsed sections, their order, hidden sections and whether the inspector is open are remembered too, but aren't settings you edit. Section sizes are not remembered.
